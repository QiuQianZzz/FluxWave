# 播放音乐

## 搜索

通过底部导航栏进入**搜索**页，输入关键词搜索在线音乐。

## 播放控制

- 播放 / 暂停、上一首 / 下一首
- 随机播放、列表循环 / 单曲循环
- 多音质选择、试听判断

## 迷你播放栏

底部常驻，左右滑动可快速切歌。

## 全屏播放页

点击迷你播放栏展开，支持歌词逐字高亮、进度条拖拽、音质切换。

## 播放队列

播放页点击「队列」按钮打开播放队列面板：

- 行首显示序号，点击任意行可跳转播放
- 面板顶部的「第 N 首」可定位当前歌曲
- 右下角按钮可清空队列，或切换「原始顺序 / 随机顺序」视图

## 系统通知栏控制

播放时系统通知栏显示控制按钮：收藏、上一首、播放/暂停、下一首。
