# 设置与账号

## 账号

登录 / 退出在线音乐账号，支持二维码扫码登录。登录后可同步在线音乐账号的歌单与每日推荐。

## 网络与风控

代理设置、IP 注入开关。

## 播放

- 启动后自动播放
- 音质偏好
- AMLL DB 逐字歌词（TTML，开启后优先从 AMLL DB 获取 Apple Music 级别逐字歌词）
- 背景帧率、背景律动开关

## 外观

- 深色 / 浅色模式
- 界面毛玻璃
- 动态取色（跟随歌曲封面）
- 手动种子色与调色板
- 预测性返回（Android）
- 切页震动
- 桌面图标（Android）

## 存储

- 缓存管理与清理、封面缓存
- 备份与恢复：导出 / 导入数据备份

## 关于

版本信息、应用日志（查看 / 导出 / 清理）、更新检查与更新渠道。
