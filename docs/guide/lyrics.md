# 歌词与播放页体验

## 流体动态背景

播放页背景随封面主色流动渐变，切换歌曲时平滑过渡、不闪烁。

## 强调色主题

播放按钮、进度条、歌词高亮等元素自动使用封面可读强调色；浅色封面会被自动压暗，保证文字清晰。

## 歌词动画

- 支持 LRC / YRC / NRC / TTML 四种格式，逐字卡拉 OK 高亮
- Apple Music 风格弹簧滚动动画，前奏 / 间奏显示呼吸圆点
- 歌词行的景深模糊强度可在设置中调节

## TTML 逐字歌词（AMLL DB）

开启「AMLL DB 逐字歌词」后，优先从 AMLL DB 获取 Apple Music 级别的 TTML 逐字歌词：

- 三级缓存：进程内 LRU → 磁盘（`lyrics_ttml.txt`）→ AMLL DB 网络
- 多镜像源自动降级，首个失败自动切换下一个
- TTML 无逐字数据时自动降级到网易云 YRC / LRC
- 支持背景人声（x-bg）显示
- 翻译语言自动选择（简体 > 繁体 > 中文变体）
- 关闭后回退到网易云自带歌词（LRC / YRC）

关闭 / 开启开关后切回播放页即时生效，无需重启。

## 节奏律动

开启后背景随音乐节拍脉冲。

## 背景帧率

设置 → 播放 → 背景帧率，三档可选：

- **省电（30fps）**：低功耗设备或长时间播放推荐
- **均衡（60fps）**：默认，兼顾流畅与功耗
- **流畅（无限制）**：跟随屏幕刷新率，高刷屏体验最佳，功耗最高
