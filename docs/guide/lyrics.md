# 歌词与播放页体验

## 流体动态背景

播放页背景随封面主色流动渐变，切换歌曲时平滑过渡、不闪烁。

## 强调色主题

播放按钮、进度条、歌词高亮等元素自动使用封面可读强调色；浅色封面会被自动压暗，保证文字清晰。

## 歌词动画

- 支持 LRC / YRC / NRC 三种格式，逐字卡拉 OK 高亮
- Apple Music 风格弹簧滚动动画，前奏 / 间奏显示呼吸圆点
- 歌词行的景深模糊强度可在设置中调节

## 节奏律动

开启后背景随音乐节拍脉冲。

## 背景帧率

设置 → 播放 → 背景帧率，三档可选：

- **省电（30fps）**：低功耗设备或长时间播放推荐
- **均衡（60fps）**：默认，兼顾流畅与功耗
- **流畅（无限制）**：跟随屏幕刷新率，高刷屏体验最佳，功耗最高
