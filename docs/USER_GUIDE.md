# FluxWave 用户指南

## 简介

FluxWave 是一款跨平台聚合音乐播放器，支持 Android、Windows。提供在线音乐搜索播放、逐字歌词、本地收藏、播放统计等功能。

## 功能介绍

### 播放音乐

- **搜索**：通过底部导航栏进入搜索页，输入关键词搜索在线音乐
- **播放控制**：支持播放/暂停、上一首/下一首、随机播放、列表循环/单曲循环
- **迷你播放栏**：底部常驻，左右滑动可快速切歌
- **全屏播放页**：点击迷你栏展开，支持歌词逐字高亮、进度条拖拽、音质切换
- **播放队列**：播放页点击「队列」按钮打开，行首显示序号、点击可跳转播放；面板顶部的「第 N 首」可定位当前歌曲；右下角按钮可清空队列，或切换「原始顺序 / 随机顺序」视图

### 我的

- **本地**：查看「我喜欢的音乐」收藏列表与播放记录
- **在线**：登录后同步在线音乐账号的歌单与每日推荐
- **播放统计**：按日 / 周 / 月查看播放时长、播放热力图与歌曲排行

### 收藏音乐

- 在播放页点击红心按钮收藏当前歌曲
- 收藏的歌曲可在「我的 → 我喜欢的音乐」中查看
- 支持从收藏列表中取消收藏

### 系统通知栏控制

播放时系统通知栏显示控制按钮：收藏、上一首、播放/暂停、下一首。

### 播放页体验

- **流体动态背景**：播放页背景随封面主色流动渐变，切换歌曲时平滑过渡
- **强调色主题**：播放按钮、进度条、歌词高亮等元素自动使用封面可读强调色；浅色封面会被自动压暗，保证文字清晰
- **歌词动画**：逐字卡拉 OK 高亮 + Apple Music 风格弹簧滚动动画，前奏/间奏显示呼吸圆点；歌词行的景深模糊强度可在设置中调节
- **节奏律动**：开启后背景随音乐节拍脉冲
- **背景帧率**：设置 → 播放 → 背景帧率，三档可选：
  - 省电（30fps）：低功耗设备或长时间播放推荐
  - 均衡（60fps）：默认，兼顾流畅与功耗
  - 流畅（无限制）：跟随屏幕刷新率，高刷屏体验最佳，功耗最高

### 设置

- **账号**：登录/退出在线音乐账号，支持二维码扫码登录
- **网络与风控**：代理设置、IP 注入开关
- **播放**：启动后自动播放、音质偏好、背景帧率、背景律动开关
- **外观**：深色/浅色模式、界面毛玻璃、动态取色（跟随歌曲封面）、手动种子色与调色板、预测性返回（Android）、切页震动、桌面图标（Android）
- **存储**：缓存管理与清理、封面缓存、备份与恢复
- **关于**：版本信息、应用日志（查看 / 导出 / 清理）、更新检查与更新渠道

## 常见问题

### 无法播放音乐

- 检查网络连接
- 部分歌曲可能因版权限制无法播放，尝试搜索其他版本

### 代理设置

- 默认直连，不使用系统代理
- 如需使用代理，请设置 HTTP_PROXY/HTTPS_PROXY 环境变量后在设置中开启
- TUN/VPN 模式会在网卡层接管流量，无法靠本应用绕过

### 数据存储

- 播放记录、收藏、设置等数据存储在本地数据库
- 音频缓存存储在应用私有目录
- 可在「设置 → 存储 → 备份与恢复」导出 / 导入数据备份
